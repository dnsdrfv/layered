# LAYERED — гардероб-коллаж

MVP веб-приложения для iPhone (PWA): фотографируешь вещь → фон вырезается → выбираешь тип → вещь сама встаёт на свой слой → собираешь образ на манекене → сохраняешь.

Собрано по прототипу «Гардероб-коллаж — lo-fi прототип iPhone» (hi-fi страница).

## Как пользоваться на iPhone

1. Открыть адрес приложения в Safari.
2. «Поделиться» → «На экран „Домой“» — откроется как отдельное приложение, работает офлайн.
3. «+» → сфотографировать вещь на контрастном фоне (или выбрать из галереи).
4. Проверить вырезку («До / После»), при необходимости «Поправить края» или «Вырезать нейросетью».
5. Выбрать тип вещи — слой назначается автоматически (таблица слоёв на экране).
6. «Примерить» — вещь встаёт на манекен. В коллаже вещи можно таскать и масштабировать двумя пальцами.
7. «Готово» → название, повод, погода → «Сохранить в образы». Опционально — карточка 9:16 для сторис.

Пустой гардероб? Кнопка «Загрузить примеры» добавит 6 векторных вещей для пробы.

## Технологии

- Чистые HTML / CSS / JS (ES-модули), без сборки и зависимостей.
- Хранение: IndexedDB (вещи с PNG-вырезками, образы с миниатюрами) — всё на устройстве.
- Вырезка фона: собственный алгоритм заливки от краёв кадра (быстро, офлайн); опционально нейросеть `@imgly/background-removal` с CDN (скачивает модель ~40 МБ при первом использовании).
- Слои: `tee 3`, `shirt/sweater 4`, `vest 5`, `jacket 6`, `pants/skirt 2 (один слот)`, `shoes 2`, `accessory 7`; манекен — слой 1.
- PWA: `manifest.webmanifest` + `sw.js` (оболочка офлайн, обновления сразу).

## Запуск локально

```bash
python3 -m http.server 8080
```

Открыть <http://localhost:8080>. Камера и установка PWA требуют HTTPS или localhost.

## Деплой

Публикуется из ветки `main` через GitHub Pages (корень репозитория). Любой пуш в `main` обновляет приложение.

## Структура

```
index.html            разметка, SVG-иконки и манекен
styles.css            стили (мобильные, safe-area)
app.js                состояние, IndexedDB, вырезка, редактор, экраны
sw.js                 service worker
manifest.webmanifest  PWA-манифест
icons/                иконки приложения
```
